# Personal Portfolio

Portofolio personal statis berbasis HTML, CSS, dan JavaScript. Situs ini tidak
membutuhkan Python, backend, atau proses build untuk dijalankan.

## Menjalankan secara lokal

Buka `index.html` langsung di browser. Pastikan gambar berikut tetap berada
sefolder dengan halaman:

- `profile-portrait.png`
- `profile-campus.png`

Foto laboratorium, gambar teknologi, dan font dimuat dari layanan eksternal,
jadi bagian tersebut memerlukan koneksi internet.

## Publikasi lewat GitHub Pages

1. Unggah isi repositori ini ke branch `main`.
2. Buka **Settings → Pages** di repositori GitHub.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu simpan.
5. Buka alamat situs yang ditampilkan pada halaman Pages setelah deployment
   selesai.

`index.html` dan kedua gambar profil berada di root repositori agar GitHub Pages
dapat menyajikannya sebagai situs statis.
